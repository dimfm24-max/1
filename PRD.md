# DiLife — техническое задание

Веб-приложение для планирования дня, привязанного к целям. Собрано из ответов на 140 вопросов, 21.09.2026.

## 1. Суть продукта

DiLife помогает человеку идти к большой цели через распорядок дня. Большая цель разбивается на средние, средние — на этапы, этапы — на шаги. Шаги попадают в план дня. Человек видит, что каждый прожитый день двигает его к цели.

Для кого: человек, который сам ведёт свои цели. Наставников, коучей и командной работы нет.

Три опоры продукта: планирование дня, мотивация, дисциплина.

## 2. Структура целей

Четыре уровня:

1. **Дело вашей жизни** — вершина. Одно на человека. Без срока. Своего расчёта продвижения не имеет, только объединяет цели.
2. **Цель** — срок обязателен. Есть измеримый показатель.
3. **Этап** — часть цели.
4. **Шаг** — самое мелкое действие внутри этапа.

Завести цель, не заведя «Дело вашей жизни», нельзя. «Дело вашей жизни» одно, поэтому перенос целей между делами жизни не предусмотрен.

Целей одновременно может быть сколько угодно. Одна помечается главной.

### Измерение продвижения цели

Пользователь сам пишет единицу измерения и целевое число: «60 килограммов», «300 страниц», «12 занятий».

Для каждой цели выбирается способ обновления показателя:

- вручную, когда есть что записать;
- автоматически из выполненных шагов.

### Срок цели

Срок обязателен. Пользователь выбирает дату в календаре.

Когда срок наступил, а цель не закрыта, приложение спрашивает: продлить, закрыть или отказаться от цели.

Приложение предупреждает о приближении срока. За сколько дней — настраивается.

### Завершение цели

При закрытии цели пользователь оставляет заметку об итоге: что получилось, что понял.

Завершённые и брошенные цели уходят в архив и доступны для просмотра. Цель из архива можно вернуть в работу с новым сроком.

## 3. День

День состоит из задач. У задачи есть время начала и длительность.

| Свойство | Поведение |
| --- | --- |
| Длительность по умолчанию | 30 минут, значение настраивается |
| Пересечение задач по времени | Разрешено, приложение подсвечивает |
| Начало дня | Настраивается, по умолчанию 00:00 |
| Приоритет | Обычная, важная, срочная |
| Подзадачи | Список с галочками внутри задачи |
| Повтор | По дням недели и датам |

Задача может быть привязана к цели, но не обязана: бытовые дела живут без целей.

**Задача и шаг — разные сущности.** Задача дня ссылается на шаг цели. Шаг, который требует нескольких дней, ставится в несколько дней: каждый раз это отдельная задача.

У шага есть необязательная оценка времени.

Шаг попадает в расписание вручную: перетаскиванием или кнопкой. Автоматически приложение шаги не расставляет.

### Создание распорядка

Распорядок собирается из шаблона дня и правится руками. Шаблонов может быть сколько угодно, каждый со своим названием: будни, выходной, день тренировки.

Задачи в расписании двигаются мышью. Быстрое добавление: написал название в одно поле — задача появилась.

### Выполнение

Выполнение отмечается галочкой. К задаче можно приложить результат: текст, фотографии, файлы, ссылки.

### Конец дня

Невыполненная задача либо сгорает, либо переносится — выбирает пользователь. Перенос по умолчанию на завтра, можно выбрать другую дату.

Сгоревшие задачи остаются в истории с пометкой.

Вечером приложение подводит итог дня: что сделано, что осталось, и спрашивает про перенос. Итог приходит за час до конца дня, время настраивается.

Если человек не заходил неделю, приложение показывает сводку пропущенного и предлагает разобрать.

## 4. Привычки

Привычка — отдельная сущность со своей полосой выполнения по дням.

Расписание гибкое, с интервалами: каждый день, по дням недели, через день, раз в три дня.

**Пропуск запланированного дня обрывает серию.** Серия обнуляется, сама привычка продолжает существовать. Дни, которые не входят в расписание, серию не рвут.

## 5. Горизонт жизни

Раздел показывает, сколько времени у человека впереди.

Пользователь вводит дату рождения и ожидаемую продолжительность жизни. По умолчанию — 80 лет.

Показывается двумя способами одновременно:

- сетка недель: прожитые закрашены, оставшиеся пустые;
- крупные числа: осталось лет, месяцев, недель, дней.

Раздел входит в ядро продукта и не отключается. Говорит тем тоном, который человек выбрал в настройках.

## 6. Разделы приложения

| Раздел | Содержание |
| --- | --- |
| Сегодня | План на день, продвижение главной цели, дней до её срока, цитата дня |
| Цели | Дерево: дело жизни, цели, этапы, шаги. Архив |
| Привычки | Список привычек с полосами выполнения |
| Календарь | Горизонт жизни, а также год, месяц, неделя, день |
| Статистика | Выполнение по дням, время по целям, серии привычек, движение целей |
| Заметки | Свободные записи, с привязкой к цели или без |
| Настройки | Тон, оформление, уведомления, категории, шаблоны дня, профиль, данные |

Заметки живут и отдельным разделом, и внутри целей и задач.

Шапка приложения: название, поиск, уведомления, профиль.

Статистика доступна за неделю, месяц и год.

## 7. Первый вход

Мастер обязателен, четыре шага:

1. Тон обращения.
2. Горизонт жизни.
3. Дело вашей жизни.
4. Первая цель с этапами и шагами.

Назад вернуться можно, введённое сохраняется.

На пустых экранах — короткое объяснение и кнопка создания.

## 8. Мотивация

- Видимое продвижение: полосы, проценты, серии дней.
- Свои цитаты. Пользователь ведёт собственный список. Одна цитата показывается на главной и меняется каждый день.

## 9. Тон обращения

Приложение обращается на «ты». Тон выбирает пользователь, четыре варианта:

- дружелюбный;
- подстёгивающий;
- уважительный;
- нейтральный.

Тон спрашивается в первом мастере. Выбранный тон действует везде, включая «Горизонт жизни».

## 10. Уведомления

Приходят уведомлениями браузера, с разрешения пользователя.

| Вид | Когда |
| --- | --- |
| Напоминание о задаче | Время задаёт пользователь |
| Приближение срока цели | За настраиваемое число дней |
| Утреннее приветствие с планом | В начало дня из настроек |
| Итог дня | За час до конца дня |
| Новый комментарий | Сразу |

Каждый вид включается отдельным переключателем.

Защита от потока: не больше одного напоминания в 15 минут, остальные собираются в одно.

## 11. Доступ по ссылке

Владелец может открыть свой профиль по ссылке.

- Владелец отмечает, какие разделы видны: цели, привычки, статистика.
- Отдельную цель можно спрятать пометкой «личное».
- Ссылка работает без входа в DiLife.
- Ссылку можно отозвать в любой момент, старая перестаёт работать.
- На странице владелец подписан именем и фотографией из профиля.

### Комментарии

Оставить комментарий может любой, кто открыл ссылку. Имя он указывает вручную.

Владелец получает уведомление о новом комментарии и может удалить любой комментарий в своём профиле.

Лент, друзей и сравнения результатов в продукте нет.

## 12. Персонализация

| Что | Как |
| --- | --- |
| Категории задач | Свой список с цветами: работа, спорт, семья |
| Цвет задачи | По категории, можно задать свой у конкретной задачи |
| Оформление | Светлая тема, тёмная, как в системе |
| Фон | Набор готовых оформлений плюс свой цвет |
| Поля задач и целей | Свои поля: текст, число, дата, список вариантов, флажок |
| Шаблоны дня | Сколько угодно |
| Начало дня, длительность по умолчанию | Настраиваются |

## 13. Учётная запись и данные

- Вход по почте и паролю. Почта подтверждается письмом.
- Пароль не короче 8 символов.
- Часовой пояс определяется автоматически, меняется вручную.
- Профиль: имя, фотография, почта, часовой пояс, настройки приложения.
- Данные видит владелец и те, кому он дал ссылку.
- Выгрузка данных: один файл со всем содержимым плюс папка с вложениями.
- Удаление аккаунта со всеми данными — из настроек, с подтверждением.

Удаление задачи или цели: сначала корзина, через 30 дней — насовсем.

При удалении «Дела вашей жизни» приложение спрашивает: удалить вместе с целями или открепить цели.

| Длина описания | Без предела |
| Количество целей, задач, заметок | Без ограничений |

## 15. Поиск

Ищет по названиям и описаниям целей, этапов, шагов, задач и заметок.

## 16. Поведение и скорость

- План на сегодня открывается мгновенно. Остальные разделы могут думать до секунды.
- При потере связи — сообщение «нет связи» и повтор при восстановлении.
- Формат времени 24 часа, дата вида 21.09.2026.
- Язык интерфейса только русский.

## 17. Страница-описание

Отдельная публичная страница для тех, кто ещё не зарегистрирован: суть продукта, четыре уровня целей, снимки экранов, кнопка регистрации.

## 18. Мобильное приложение

В первой версии повторяет браузерное: день, цели, привычки.

## 19. Что не входит в первую версию

- Работа без интернета.
- Связь с внешними календарями Google и Apple.
- Платные возможности и подписки.
- Английский язык.
- Друзья, лента, сравнение результатов.
- Баллы, уровни, достижения.
- Отдельная выгрузка статистики.

## 20. Как поймём, что продукт работает

Человек возвращается и ведёт день хотя бы 5 дней из 7.

Первые пользователи — автор и около десяти знакомых. После запуска смотрим, где люди застревают, и чиним. Внутри приложения — простая форма «написать разработчику».

## 21. Порядок сборки

Собираем по частям, каждая часть работает сразу:

1. Вход и учётная запись.
2. Цели: дело жизни, цели, этапы, шаги.
3. День: задачи, шаблоны, выполнение, перенос.
4. Привычки.
5. Горизонт жизни.
6. Статистика.
7. Заметки.
8. Календарь.
9. Доступ по ссылке и комментарии.
10. Страница-описание.

Объём первой версии не сокращаем.

## 22. Открытые вопросы

1. **Горизонт жизни как обязательный раздел.** Счётчик оставшегося времени отключить нельзя. Риск: человеку в тяжёлый период это может навредить. Смягчение — выбранный тон обращения. Стоит вернуться к вопросу после первых отзывов.
