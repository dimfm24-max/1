## Подводные камни

- Интерфейс только русский, первые пользователи — знакомые автора. Если они в России, `docs/DEPLOYMENT.md` требует Yandex Cloud. Почта тогда — Postbox (`CHECKLIST.md`, раздел «Решения агента»).
- Продукт хранит почту, имя, фото и дату рождения. Это персональные данные. Нужны ли политика конфиденциальности и согласие — решает владелец (вопрос ниже).
- В Yandex Cloud API масштабируется на несколько процессов, поэтому счётчики частоты живут в БД (`RATE_LIMIT_STORE=database`). Новые бюджеты из задач 05, 29, 38 должны работать и с этим хранилищем.
- Значение `INGRESS_RATE_LIMIT_PROVIDER=yandex-sws` выключает все локальные бюджеты: `rateLimitEnabled` в `backend/src/app.ts` общий для них. Граница сети (Smart Web Security) считает запросы по адресу и не знает ссылки доступа, почты или человека. Бюджеты по ссылке (задача 29), по почте (задача 05) и по человеку (задача 38) этим значением выключаться не должны. Сейчас Terraform не задаёт переменную, и действует `local`.
- Перед облачными действиями проверь remote, рабочее дерево и ветку релиза (AGENTS.md). Грязное дерево или неопубликованный код — стоп.
- `docs/DEPLOYMENT.md` требует `bun run check` перед релизом. Сейчас он красный из-за известного ограничения `scripts/template-check.test.mjs` (`CHECKLIST.md`, раздел «Проверка окружения»). Реши до релиза, какие проверки его заменяют, и запиши это.
