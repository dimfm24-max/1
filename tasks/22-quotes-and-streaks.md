# 22. Мотивация: свои цитаты и серии дней

| Поле | Значение |
| --- | --- |
| ТЗ | §8 «Мотивация» (полосы, проценты, серии дней; свои цитаты, одна на главной, меняется каждый день), §6 (цитата дня на «Сегодня») |
| Этап сборки | 3. День |
| Зависит от | 02, 06, 21 |
| Состояние | частично |

## Что есть сейчас

- Полосы и проценты есть у целей и у итога дня. Серии есть у привычек.
- Цитат нет.
- Серии дней, в которые человек ведёт план, нет.

## Что сделать

1. «Настройки → Цитаты»: список цитат человека; добавить (текст и необязательный автор), изменить, удалить.
2. Цитата дня на «Сегодня» (задача 23): одна на день, одинаковая весь день, завтра — другая.
3. Выбор цитаты дня детерминирован: зависит от даты и списка, а не от случайности при каждой загрузке.
4. Стартовый набор: при первом входе человек получает несколько цитат. Их можно изменить и удалить. Пустой список — вместо цитаты приглашение добавить свою.
5. Серия дней на «Сегодня»: «ведёшь день N дней подряд». Источник — дни активности из задачи 21. Определение «вёл день» — там же.

## Критерии приёмки

- [ ] Цитаты добавляются, меняются и удаляются.
- [ ] Цитата дня не меняется при перезагрузке и на другом устройстве в тот же день.
- [ ] На следующий день показывается другая цитата, если их больше одной.
- [ ] Серия дней растёт на один за каждый день ведения плана и обнуляется после пропуска.
- [ ] Новый аккаунт получает стартовые цитаты один раз. Удалённая стартовая цитата не возвращается.

## Подводные камни

- Добавление или удаление цитаты посреди дня сдвинет выбор, если индекс считается от длины списка. Рекомендация: запоминать цитату дня на сервере для даты.
- Удаление цитаты, которая показана сегодня, — выбрать другую.
- «Сегодня» — по правилу задачи 02, иначе цитата сменится в полночь при начале дня 04:00.
- Длина цитаты: §14 ограничивает названия, а цитата — текст. Правило — в задаче 37.
- Стартовые цитаты — только тексты, которые можно свободно использовать: пословицы и высказывания авторов, умерших более 70 лет назад. Набор на русском утверждает владелец.
- Стартовый набор создаётся один раз, по признаку в настройках. Существующие аккаунты получают его при первом открытии после выпуска.
