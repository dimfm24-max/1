# 28. Календарь: горизонт, год, месяц, неделя, день

| Поле | Значение |
| --- | --- |
| ТЗ | §6 (Календарь: горизонт жизни, а также год, месяц, неделя, день) |
| Этап сборки | 8. Календарь |
| Зависит от | 13, 15, 18, 23, 25 |
| Состояние | частично |

## Что есть сейчас

- `/app/calendar` (`webapp/src/features/calendar`): месяц из шести недель с понедельника. Отмечены сроки целей в работе.
- Горизонт жизни — отдельный раздел `/app/horizon`.
- Года, недели и дня нет. Задачи в календаре не видны.
- API для сводки по диапазону дат нет: день читается только целиком по одной дате.

## Что сделать

1. Вкладки календаря: Горизонт жизни (задача 25), Год, Месяц, Неделя, День.
2. Год: 12 месяцев; дни с задачами показаны насыщенностью по доле выполненных; сроки целей.
3. Месяц: сроки целей, число задач в дне и выполненные.
4. Неделя: семь колонок со шкалой времени. Задачу можно перетащить на другой день и время.
5. День: тот же план, что на «Сегодня» (задача 23), для выбранной даты.
6. Щелчок по дню в годе, месяце и неделе открывает этот день.
7. Будущие повторы (задача 18) видны.
8. API: сводка по диапазону дат одним запросом.

## Критерии приёмки

- [ ] Пять вкладок переключаются, выбранная дата сохраняется между ними.
- [ ] Перетаскивание задачи в неделе меняет её день и время.
- [ ] Год открывается одним запросом, не 365.
- [ ] Удалённые задачи не видны.

## Подводные камни

- Перенос задачи на другой день перетаскиванием требует смены даты в правке задачи (задача 13).
- Неделя начинается с понедельника (как в текущем месяце).
- Будущие повторы: показывай ожидаемые появления без записи в БД (задача 18).
- Начало дня позже 00:00 (задача 02): задача после полуночи относится к предыдущему дню плана.
- Сводка по диапазону — индекс `tasks_user_id_scheduled_on_idx` уже есть. Проверь план запроса на годовом диапазоне.
- Маршрут `GET /api/day/{date}` регистрируется последним в `backend/src/modules/day/transport/routes.ts`: он ловит любой путь из одного сегмента после `/api/day/`. Новый GET-маршрут дня, например сводку по диапазону, регистрируй до него. Иначе запрос получит 400 от проверки даты.

## Решения владельца

Решено владельцем 23.09.2026.

- Что показывать в годе и месяце? **Решение:** сроки целей и число задач с долей выполненных.
