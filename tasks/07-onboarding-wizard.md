# 07. Первый вход: обязательный мастер из четырёх шагов

| Поле | Значение |
| --- | --- |
| ТЗ | §7 «Первый вход», §9 (тон спрашивается в мастере), §5 (горизонт), §2 (без дела жизни цель завести нельзя) |
| Этап сборки | 1. Вход и учётная запись |
| Зависит от | 02, 03, 06 |
| Состояние | сделано |

## Что есть сейчас

- Мастера нет. После регистрации человек попадает на шаблонную страницу `/app`.
- API уже умеет всё, что соберёт мастер: тон и горизонт (`PATCH /api/day/settings`), дело жизни, цель, этапы и шаги (`backend/src/modules/goals`).

## Что сделать

1. Экран мастера из четырёх шагов:
   1. Тон обращения — четыре варианта с примером фразы.
   2. Горизонт жизни — дата рождения и продолжительность жизни, по умолчанию 80 лет.
   3. Дело вашей жизни — название.
   4. Первая цель: название, срок, единица, «сколько сейчас» и «сколько нужно» (задача 08), способ обновления показателя — по умолчанию автоматически из шагов, минимум один этап и один шаг.
2. Мастер обязателен. Пока он не пройден, любой адрес `/app/*` ведёт в мастер. Выход из аккаунта остаётся доступным.
3. Кнопка «Назад» на каждом шаге. Введённое на всех шагах сохраняется.
4. Признак «мастер пройден» хранится на сервере.
5. После мастера человек попадает на «Сегодня» (задача 23).

## Критерии приёмки

- [ ] Новый аккаунт после регистрации попадает в мастер.
- [ ] Пока мастер не пройден, прямой переход на любой адрес `/app/*` открывает мастер.
- [ ] Возврат назад и вперёд не теряет введённое.
- [ ] Перезагрузка страницы на шаге 3 не теряет шаги 1 и 2.
- [ ] После шага 4 в дереве есть дело жизни и цель с этапами и шагами. Цель — главная.
- [ ] Пройденный мастер больше не открывается.
- [ ] Старые аккаунты с делом жизни не видят мастер.
- [ ] Шаг 4 не пропускает цель без этапа и шага.
- [ ] Шаг горизонта пропустить нельзя.
- [ ] Цель из мастера по умолчанию считает показатель автоматически из шагов.

## Подводные камни

- Шаг 4 создаёт цель, этапы и шаги. Сейчас это отдельные запросы. Сбой посередине оставит цель без части этапов. Рекомендация: один запрос «создать цель с этапами и шагами» в одной транзакции.
- Двойное нажатие «Готово» создаст две цели. Нужна защита: блокировка кнопки и идемпотентный запрос.
- Возврат к шагу 3 и правка названия должны обновить дело жизни, а не создать второе. API `upsert` для дела жизни уже есть.
- Шаги 1–3 сохраняют данные сразу. Шаг 4 — черновик в браузере до «Готово». Иначе перезагрузка потеряет цель.
- Существующие аккаунты: признак нового поля будет пустым. Считай мастер пройденным, если у человека есть дело жизни. Перенос — в модуле, не рукописным SQL.
- Срок цели выбирается в календаре (§2) и не может быть в прошлом (задача 09).
- Проверка «мастер пройден» не должна добавлять запрос перед показом «Сегодня»: план открывается мгновенно (§16, задача 23). Отдавай признак с данными, которые уже приходят при открытии. Пример — пользователь из `GET /api/auth/me`: приложение и так ждёт этот ответ до показа любого экрана. `userSchema` в `packages/contracts/src/auth.ts` не объявлен `.strict()`, поэтому новое поле старые клиенты отбросят.
- Главный путь из `CHECKLIST.md` начинается с мастера. Его проверяет E2E (задача 43).
- Главный путь заканчивается так: человек выполняет шаг и видит продвижение цели. Это работает только при способе «автоматически из шагов». Сейчас по умолчанию стоит ручной способ: `progressMode` по умолчанию `manual` в `createGoalRequestSchema` и в `webapp/src/features/goals/CreateGoalForm.tsx`. При ручном способе выполненный шаг показатель не меняет. Решение владельца: по умолчанию — автоматически из шагов.
- Владелец принял начальное значение для числовых целей (задача 08). При ручном способе мастер спрашивает «сколько сейчас». Иначе цель «60 килограммов» при весе 80 после первой записи сразу покажет 100 %.

## Решения владельца

Решено владельцем 23.09.2026.

- Можно ли пропустить шаг горизонта? **Решение:** нельзя. Текст не смягчать: горизонт говорит выбранным тоном.
- Сколько этапов и шагов минимум на шаге 4? **Решение:** один этап и один шаг.
- Какой способ обновления показателя по умолчанию? **Решение:** автоматически из шагов. Ручной способ — на выбор.
