## Что есть сейчас

- Тон хранится в `UserSettings.tone`: `friendly`, `pushing`, `respectful`, `neutral`. По умолчанию — `friendly`.
- API меняет тон (`PATCH /api/day/settings`), но экрана выбора тона нет.
- Тон влияет на одну фразу горизонта: `horizonMessage` в `webapp/src/features/horizon/pages.tsx`.

## Что сделать

1. Составить список мест, где приложение «говорит» с человеком:
   - утреннее приветствие;
   - приветствие и строка под ним на экране «Сегодня» (задача 23);
   - итог дня;
   - сводка после недели отсутствия;
   - приближение и наступление срока цели;
   - горизонт жизни;
   - пустой план дня;
   - поздравление с закрытием цели;
   - тексты уведомлений (задачи 30, 31).
2. Для каждого места написать четыре варианта текста.
3. Тексты интерфейса хранить в клиенте. Тексты уведомлений хранить на сервере. Список тонов и ключи мест — общие, в контракте.
4. Выбор тона — в мастере первого входа (задача 07) и в настройках (задача 06).
5. Смена тона действует сразу во всех местах.

## Критерии приёмки

- [x] Каждое место из списка говорит по-разному в каждом из четырёх тонов.
- [x] Все варианты обращаются на «ты».
- [x] Смена тона в настройках меняет тексты без перезагрузки страницы.
- [x] Уведомления приходят выбранным тоном.
- [x] Тест проверяет полноту каталога: для каждого тона и места текст есть.

## Подводные камни

- «Уважительный» тон на «ты» требует аккуратных формулировок. Сейчас горизонт использует «Вы» — это нарушает §9.
- Работа над стилем добавила второе место с текстами по тону: `toneLine` в `webapp/src/features/today/today-view.ts`. Уважительный тон там тоже говорит «Вас». Перенеси эти строки в каталог вместе с `horizonMessage`.
- Подстёгивающий тон рядом с горизонтом жизни — риск из §22. Решение владельца (задача 07): горизонт говорит выбранным тоном без особого смягчения. Риск остаётся открытым вопросом ТЗ. Не добавляй смягчение без нового решения.
- Храни тексты в одном каталоге. Не раскладывай их по компонентам: иначе новый тон или правка текста затронет десятки файлов.
- Тесты не проверяют формулировки (AGENTS.md). Они проверяют, что текст выбран по тону.

## Решения владельца

Решено владельцем 23.09.2026.

- Кто пишет тексты для четырёх тонов? **Решение:** разработчик пишет черновик, владелец утверждает список фраз одним документом.
- Смягчать ли тексты горизонта жизни? **Решение (задача 07):** нет. Горизонт говорит выбранным тоном.
