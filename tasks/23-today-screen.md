## Что есть сейчас

- `/app` — шаблонная страница «Welcome» со сводкой аккаунта: `webapp/src/features/users/pages.tsx`, `AccountSummary.tsx`.
- План дня живёт на `/app/day`.
- Главная цель видна только в разделе «Цели» по метке «Главная».
- Маршруты загружаются лениво (`lazyRouteComponent` в `webapp/src/routes.tsx`), но все они берут компоненты из одного модуля `webapp/src/pages.tsx`. Он статически импортирует все фичи. Поэтому код «Сегодня» приходит вместе с первым любым маршрутом, а размер этого общего чанка растёт с каждым экраном.
- Группа `vendor` в `webapp/vite.config.ts` собирает в один чанк все модули `node_modules`, кроме React и TanStack.
- Первое открытие идёт цепочкой: код маршрута → восстановление сессии (`POST /api/auth/refresh`, `webapp/src/features/auth/bootstrap.ts`) → пользователь (`GET /api/auth/me`, `webapp/src/features/auth/provider.tsx`) → запросы данных. Пока нет ответа `me`, оболочка показывает загрузку (`auth.isBootstrapping` в `webapp/src/pages.tsx`). День и контекст дня запрашиваются параллельно.
- Кэш запросов живёт только в памяти вкладки. `webapp/src/main.tsx` задаёт `staleTime: 30_000` и не задаёт `gcTime`, поэтому действует значение TanStack Query по умолчанию — 5 минут.

## Что сделать

1. «Сегодня» на `/app`:
   - план на сегодня: шкала (задача 15), быстрое добавление (задача 13), шаги целей (задача 16);
   - продвижение главной цели: полоса и процент;
   - дней до срока главной цели;
   - цитата дня (задача 22);
   - приветствие тоном человека (задача 03);
   - предупреждения о сроках (задача 09);
   - вход в вечерний итог (задача 20);
   - строка привычек на сегодня: отметка одним касанием (решение владельца, задача 24).
2. Нет главной цели — приглашение выбрать или создать её.
3. Переход к другим дням — стрелками на этом экране и через «Календарь» (задача 28).
4. Скорость: план на сегодня виден сразу. Данные запрашиваются после входа и держатся в кэше. Экран рисуется из кэша и обновляется в фоне.

## Критерии приёмки

- [ ] `/app` показывает план, главную цель, дни до срока и цитату.
- [ ] Выполнение шага из плана сразу меняет полосу главной цели.
- [ ] Повторное открытие «Сегодня» показывает план без индикатора загрузки.
- [ ] Первое открытие после входа — не дольше 1 секунды на обычном соединении. Замер записан в отчёте задачи.
- [ ] В начале нового дня открытая вкладка переходит на новый день.
- [ ] Привычку на сегодня можно отметить прямо на «Сегодня».

## Подводные камни

- «Мгновенно» нужно измерить. Рекомендация: повторное открытие — из кэша без ожидания сети; первое — не дольше 1 секунды.
- Кэш без наблюдателя удаляется через `gcTime`. Человек провёл больше 5 минут в «Целях» — возврат на «Сегодня» снова покажет загрузку. Для запросов «Сегодня» подними `gcTime`, например до конца дня.
- Перезагрузка страницы и новая вкладка начинают с пустого кэша: это снова первое открытие. Сохранение кэша в браузере — новая зависимость (persister TanStack Query) и личные данные на диске, которые нужно стирать при выходе. Рекомендация: не сохранять. «Мгновенно» — возврат на «Сегодня» внутри открытой вкладки. Первое открытие — не дольше 1 секунды. Запиши это прочтение §16 в `CHECKLIST.md`.
- При первом открытии данные ждут два последовательных запроса: `refresh` и `me` (см. «Что есть сейчас»). На медленной сети на них уходит заметная часть секунды. Не добавляй в цепочку новых шагов (проверка мастера — задача 07). Сократить её можно, если `POST /api/auth/refresh` отдаёт и пользователя. `cookieRefreshResponseSchema` объявлен `.strict()`: такое изменение выпускай по общему правилу контрактов из [README](README.md).
- Тяжёлые библиотеки других экранов замедлят первое открытие «Сегодня». Графики статистики (`recharts`, задача 26), перетаскивание (задача 15), свои поля даты (задача 01) попадут в общий чанк `pages.tsx` и в `vendor`. Выдели тяжёлые экраны в отдельные чанки. Сверяй размер чанков после `bun run build:webapp`.
- Дерево целей, день и контекст на «Сегодня» запрашивай параллельно, не вложенными компонентами. Либо сделай один запрос «сегодня».
- Экран дня и «Сегодня» — один компонент. Не делай два разных экрана одного плана.
- Закрытая или удалённая главная цель не показывается (задачи 10, 11).
- Работа над стилем уже собрала «Сегодня» в `webapp/src/features/today` (рабочая копия). Четыре расхождения с этой задачей:
  - `pickMainGoal` в `webapp/src/features/goals/goal-view.ts` показывает первую цель в работе, если главной нет или она закрыта. Человек не выбирал эту цель главной. Это расходится с п. 2 и с задачей 10: закрытие главной цели предлагает выбрать новую. Показывай приглашение выбрать главную цель, а не подставляй её молча.
  - Кнопка «Добавить задачу» уводит на `/app/day`. П. 1 требует быстрое добавление на самом экране (§3, задача 13).
  - Плитка серий `HabitStreaksTile` запрашивает список привычек. Этот ответ несёт все отметки за всё время (задача 24) и растёт каждый день. Без окна дат в запросе «Сегодня» с каждым месяцем открывается медленнее.
  - Лента плана `TodayTimeline` в `webapp/src/features/day/TodayWidgets.tsx` не отмечает пересечения задач: `overlappingTaskIds` вызывает только экран дня. §3 требует подсветки пересечений, а «Сегодня» — главный экран плана. Общая строка ленты — задача 45.
