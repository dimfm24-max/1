## Что есть сейчас

- API закрывает цель как `completed` или `abandoned` с необязательной заметкой (`closeGoalRequestSchema` в `packages/contracts/src/goals.ts`). API возвращает цель в работу с новым сроком (`/reopen`).
- Экран: «Завершить» закрывает цель сразу как `completed`, без заметки. Кнопки «Отказаться» нет.
- «Вернуть в работу» ставит срок «через месяц» без выбора (`monthFromNow` в `webapp/src/features/goals/GoalCard.tsx`).
- Архив — список закрытых целей под целями в работе на той же странице.
- Закрытая цель доступна только для чтения.
- Закрытие не снимает отметку «главная»: `primaryGoalId` у дела жизни не меняется.
- `POST /api/goals/goals/{goalId}/primary` принимает цель любого статуса: `setPrimaryGoal` в `backend/src/modules/goals/infrastructure/goals-repository.ts` не проверяет статус. Закрытую цель можно сделать главной.

## Что сделать

1. «Завершить» и «Отказаться» открывают окно итога: что получилось, что понял. Текст итога обязателен. К итогу можно приложить фото, файлы и ссылки, как к результату задачи (задача 19).
2. Архив — вкладка раздела «Цели»: завершённые и брошенные цели, итог, дата закрытия, дерево только для чтения.
3. «Вернуть в работу» — выбор нового срока в календаре (задача 09).
4. Закрытие главной цели снимает отметку и предлагает выбрать новую главную цель из целей в работе. Сервер отказывает, если главной делают закрытую цель.
5. Поздравление при завершении — тоном человека (задача 03).

## Критерии приёмки

- [ ] Цель закрывается как завершённая или брошенная, с итогом.
- [ ] Архив показывает обе группы и итог каждой цели.
- [ ] Возвращённая цель получает выбранный срок и снова доступна для правки.
- [ ] Закрытая цель никогда не остаётся главной. Запрос «сделать главной» для закрытой цели отклоняется. Интеграционный тест.
- [ ] «Сегодня» (задача 23) не показывает закрытую цель как главную.
- [ ] Без текста итога цель не закрывается: проверка в контракте и на сервере.
- [ ] Файлы итога видны в архиве и попадают в выгрузку (задача 40).

## Подводные камни

- Будущие задачи дня, привязанные к шагам закрытой цели, остаются в плане. Рекомендация: показать пометку «цель закрыта» и предложить убрать их.
- Автоматический показатель закрытой цели замирает. Возврат в работу снова его пересчитывает.
- Повторное закрытие после возврата перезапишет прошлый итог. Рекомендация: сохранять прошлый итог, например заметкой цели (задача 27).
- Доступ по ссылке (задача 29) показывает статус цели. Проверь, как архив выглядит на публичной странице.
- Сейчас `closeGoalRequestSchema` разрешает пустой итог. Обязательный итог меняет контракт: старая вкладка без текста итога получит отказ. Выпускай вместе с клиентом.
