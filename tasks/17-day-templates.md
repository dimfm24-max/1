# 17. Шаблоны дня

| Поле | Значение |
| --- | --- |
| ТЗ | §3 «Создание распорядка» (распорядок из шаблона, правка руками, шаблонов сколько угодно, у каждого название), §12 (шаблоны дня), §6 (шаблоны в настройках) |
| Этап сборки | 3. День |
| Зависит от | 06, 13, 14; автоприменение — 18 |
| Состояние | частично |

## Что есть сейчас

- API шаблонов: создать, удалить, добавить пункт, удалить пункт, применить к дате (`/api/day/templates*`, `/api/day/template-items/{itemId}`).
- API не умеет переименовать шаблон и изменить пункт.
- Экран дня применяет шаблон (`ApplyTemplatePanel` в `webapp/src/features/day/pages.tsx`), если шаблоны уже есть.
- Создать шаблон и его пункты на экране негде: хуки `useCreateTemplateMutation` и `useCreateTemplateItemMutation` не используются.
- Применение добавляет задачи к дню, не заменяя существующие.
- `applyTemplate` создаёт задачи по одной без транзакции.

## Что сделать

1. «Настройки → Шаблоны дня»: список шаблонов; создать с названием (будни, выходной, день тренировки); переименовать; удалить.
2. Пункты шаблона: название, время, длительность, приоритет, категория. Добавить, изменить, удалить.
3. Применение к дню — на экране дня и на «Сегодня». После применения задачи правятся руками как обычные.
4. Добавить в API переименование шаблона и правку пункта.
5. Применять шаблон одной транзакцией.
6. Автоприменение по выбору человека. У шаблона есть правило: «вручную» (по умолчанию), «каждый день», «по дням недели» (выбор дней), «по числам месяца» (выбор чисел). Приложение само добавляет задачи шаблона в подходящие дни. Правило устроено так же, как повтор задач (задача 18): код правила общий.
7. «Сохранить день как шаблон», если останется время: задачи дня становятся пунктами нового шаблона.

## Критерии приёмки

- [ ] Шаблон создаётся, переименовывается и удаляется в настройках.
- [ ] Пункты шаблона создаются, меняются и удаляются.
- [ ] Применение шаблона добавляет все его пункты задачами дня.
- [ ] Применение после удаления категории пункта работает: задача получается без категории.
- [ ] Сбой посреди применения не оставляет половину задач.
- [ ] Шаблон с правилом «пн, ср, пт» сам появляется в эти дни, один раз на день.
- [ ] Изменение шаблона не меняет задачи, уже добавленные в прошлые дни.

## Подводные камни

- Висящий `categoryId` в пункте после удаления категории ломает применение на внешнем ключе задач. Подробности — в задаче 14.
- `applyTemplate` без транзакции: ошибка на третьем пункте оставит два. Нужна транзакция.
- Повторное применение того же шаблона к тому же дню дублирует задачи. Рекомендация: предупредить «шаблон уже применён сегодня».
- Время пунктов считается по правилу начала дня (задача 02).
- Применение к прошедшей дате. Рекомендация: разрешить, но с предупреждением.
- Свои поля (задача 33) в пунктах шаблона. Рекомендация: не копировать в первой версии.
- Автоприменение — один раз на шаблон и дату. Храни отметку «применён к дате». Иначе повторный проход задания или открытие дня задвоит задачи.
- Человек удалил задачу, добавленную автоматически. Шаблон не должен вернуть её в тот же день.
- Два шаблона с правилами на один день применяются оба. Покажи в настройках, что правила пересекаются.
- Не применяй шаблоны к прошедшим дням, пока человек отсутствовал (задача 21). Создание — на ближайшие дни, как у повтора (задача 18).
- Числа 29–31 есть не в каждом месяце. Рекомендация: в коротком месяце шаблон применяется в последний день месяца.
- Владелец доверил устройство автоприменения разработчику и поправит его после первой версии. Покажи владельцу экран правил до выпуска.

## Решения владельца

Решено владельцем 23.09.2026.

- Применять шаблон автоматически? **Решение:** человек сам выбирает правило: вручную, каждый день, по дням недели или по числам месяца (п. 6). Устройство — на усмотрение разработчика, владелец поправит после.
- Нужно ли «сохранить день как шаблон»? **Решение:** да, если останется время.
