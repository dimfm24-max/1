# 24. Привычки: расписание по дням недели и правка

| Поле | Значение |
| --- | --- |
| ТЗ | §4 «Привычки», §6 (список привычек с полосами выполнения) |
| Этап сборки | 4. Привычки |
| Зависит от | 01, 02, 11 |
| Состояние | почти готово |

## Что есть сейчас

- Модуль `backend/src/modules/habits` и экран `/app/habits` (`webapp/src/features/habits`).
- Расписания в API: каждый день, по дням недели, раз в N дней от даты начала.
- Полоса выполнения по дням, текущая и лучшая серия, архив.
- Серия рвётся на пропуске ожидаемого дня. Дни вне расписания серию не рвут. Сегодняшний день не засчитывается против человека до конца дня.
- Форма создания предлагает только «каждый день» и «через несколько дней». Выбора дней недели нет, хотя API его поддерживает.
- Название и расписание нельзя изменить на экране.
- «Удалить» удаляет сразу, без подтверждения.
- «Сегодня» вычисляется по часам браузера (задача 02).

## Что сделать

1. Создание и правка: название и расписание:
   - каждый день;
   - по дням недели — выбор дней, неделя с понедельника;
   - через день;
   - раз в три дня;
   - раз в N дней.
2. Удаление — через корзину (задача 11). Архив остаётся для привычек, которые человек прекратил.
3. Полоса выполнения — последние недели и прокрутка назад.
4. «Сегодня» — по правилу задачи 02.
5. Отметить привычку можно не дальше 7 дней назад. Сервер проверяет это.

## Критерии приёмки

- [ ] Привычка «пн, ср, пт» ожидается только в эти дни. Пропуск среды рвёт серию, пропуск вторника — нет.
- [ ] «Через день» и «раз в три дня» создаются одним выбором.
- [ ] Название и расписание меняются.
- [ ] Удалённая привычка лежит в корзине и восстанавливается вместе с отметками.
- [ ] Отметка 8 дней назад отклоняется сервером.
- [ ] Интеграционные тесты серии для каждого вида расписания.

## Подводные камни

- Нумерация дней в API — 0 = воскресенье (`packages/contracts/src/habits.ts`). Интерфейс показывает неделю с понедельника. Не перепутай при преобразовании.
- Смена расписания меняет прочтение прошлых дней. Серия может вырасти или оборваться задним числом. Предупреди человека.
- Отметка далёкого прошлого «чинит» оборванную серию. Реши, до какой давности можно отмечать.
- Отметка будущего дня должна быть запрещена на сервере. Сейчас `mark` в `backend/src/modules/habits/infrastructure/habits-repository.ts` принимает любую дату, в том числе раньше `startedOn`.
- `updateHabitRequestSchema` не повторяет проверку создания «выбран хотя бы один день недели». Правка может оставить расписание `weekdays` с пустым списком: привычка перестанет ожидаться. Добавь проверку на сервере с учётом сохранённых значений.
- Серия считается на сервере с «сегодня» человека (задача 02), а не с даты от клиента.
- Контракт описывает `habitSchema.marks` как отметки «в окне, которое запросил клиент». На деле `habitSelect` в `habits-repository.ts` читает все отметки за всё время, и каждый ответ списка отдаёт их все. Для прокрутки полосы назад (п. 3) добавь в запрос окно дат. Серии по-прежнему считай на сервере по всем отметкам.
