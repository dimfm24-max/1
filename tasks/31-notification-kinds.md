# 31. Уведомления: пять видов

| Поле | Значение |
| --- | --- |
| ТЗ | §10 «Уведомления» (напоминание о задаче, приближение срока цели, утреннее приветствие с планом, итог дня, новый комментарий) |
| Этап сборки | Сквозная возможность |
| Зависит от | 09, 13, 20, 29, 30 |
| Состояние | не начато |

## Что есть сейчас

- Ни одного вида уведомлений нет.

## Что сделать

Каждый вид идёт в центр уведомлений и в браузер (задача 30), если вид включён. Щелчок открывает объект.

1. **Напоминание о задаче.** В карточке задачи (задача 13) — «Напомнить». Человек задаёт точное время. Готовых вариантов вроде «за 15 минут» нет (решение владельца).
2. **Приближение срока цели.** Один раз, когда до срока осталось N дней этой цели (задача 09), и ещё раз в последний день. Время — время утреннего приветствия.
3. **Утреннее приветствие с планом.** В своё время из настроек, по умолчанию 08:00, не раньше начала дня (задача 02): число задач, первая задача по времени, главная цель. Текст — тоном человека (задача 03).
4. **Итог дня.** За час до конца дня или в настроенное время (задача 20).
5. **Новый комментарий.** Сразу после комментария на публичной странице (задача 29).

## Критерии приёмки

- [ ] Каждый вид приходит в своё время по поясу человека.
- [ ] Смена времени задачи и перенос на другую дату переносят напоминание. Выполнение, удаление и сгорание задачи отменяют его. Снятие галочки и восстановление из корзины (задача 11) возвращают напоминание, если его момент ещё впереди. Перенос и сгорание идут через `POST /api/day/tasks/{taskId}/resolve`, а не через правку задачи: проверь оба пути.
- [ ] Утреннее приветствие и итог приходят один раз в день.
- [ ] Каждый вид отключается своим переключателем.
- [ ] Unit-тесты расчёта момента отправки: пояс, начало дня, летнее время.

## Подводные камни

- Задание раз в минуту ищет наступившие уведомления. Не сканируй всех людей каждую минуту: храни «момент следующей отправки» с индексом.
- Dedupe-ключи: человек + вид + дата для ежедневных; задача + момент для напоминаний. Иначе повтор задания задвоит отправку.
- Пропуск тиков, если scheduler лежал. Рекомендация: отправить с опозданием до 30 минут, позже — пропустить. Комментарии — всегда.
- Напоминание у повторяющейся задачи (задача 18) — у каждого появления.
- Задача после полуночи при начале дня позже 00:00 (задача 02): момент — на следующей календарной дате.
- Утро без задач — отдельный текст, не пустое уведомление.
- Защита от потока (задача 30) может задержать напоминание. Напоминание, собранное в общее уведомление, теряет точность времени. Учти это в правиле сборки.
- Начало дня по умолчанию — 00:00 (§3). Поэтому у приветствия своя настройка времени (решение владельца), и предупреждение о сроке приходит в то же время.
- Уведомление о комментарии создаёт посетитель без входа. Поток комментариев не должен порождать поток строк в очереди. Рекомендация: одно ожидающее уведомление о комментариях на владельца, новые комментарии дополняют его. Образец рассуждения — `docs/BACKGROUND_JOBS.md`, раздел «Что может поставить анонимный клиент».
- Рекомендация ниже ставит предупреждение о сроке в то же время, что и утреннее приветствие. При защите от потока (задача 30) второе уведомление каждый раз уходит в общее «2 новых события» через 15 минут. Человек не увидит ни плана, ни срока. Рекомендация: включать сроки целей в текст утреннего приветствия одним уведомлением. Отдельное уведомление о сроке — только если приветствие выключено.
- У задачи без времени (задача 13) нет момента начала. Варианты «в момент начала» и «за N минут» ей недоступны: только своё время. Если у задачи снимут время, напоминание от начала отменяется или становится своим временем. Человек должен увидеть, что стало с напоминанием.

## Решения владельца

Решено владельцем 23.09.2026.

- Какие варианты времени напоминания дать? **Решение:** только своё время.
- Когда приходит утреннее приветствие при начале дня 00:00? **Решение:** своя настройка времени, по умолчанию 08:00. Предупреждение о сроке приходит в то же время.
- Уведомление о сроке — один раз или каждый день? **Решение:** один раз за N дней до срока и ещё раз в последний день.
