# Задачи DiLife: веб-приложение

Источник — [PRD.md](../PRD.md). Задачи сверены с кодом ветки `mobile` на коммите `3b02dfc` (22.09.2026).

Во время разбивки в рабочей копии шла параллельная незакоммиченная работа в `webapp`: визуальный стиль «Ночной старт», экран «Сегодня» (`webapp/src/features/today`), русское меню. После её коммита обнови раздел «Что есть сейчас» в задачах 01, 02, 03, 04, 23 и 34.

Сейчас работаем над веб-приложением: `backend`, `packages/contracts`, `webapp`. Мобильное приложение (§18) отложено по решению владельца. Его задачи появятся позже.

Каждая задача описывает разницу между ТЗ и текущим кодом. Многое уже есть: дерево целей, день, привычки, горизонт, статистика, заметки, календарь, доступ по ссылке, гостевая страница. Раздел «Что есть сейчас» в каждой задаче говорит, что именно.

## Общие правила для всех задач

- Работа идёт по [AGENTS.md](../AGENTS.md). Модули backend — `backend/src/modules/<context>`, фичи клиента — `webapp/src/features/<context>`.
- Схема БД меняется через `schema.prisma` и стандартную генерацию миграций. Рукописный SQL — только по явному запросу владельца.
- Новая зависимость — только с разрешения владельца. Разрешены 23.09.2026: `@dnd-kit` (задачи 15, 08, 28), `web-push` (задача 30), `fflate` (задача 40).
- Контракты общие с мобильным приложением. Мобильный клиент сейчас использует только вход, аватар и push. Меняй контракты совместимо.
- Клиенты разбирают каждый ответ схемой контракта: `schema.parse` в `webapp/src/platform/api/http-client.ts` и `mobile/src/platform/api/transport.ts`. Внешние схемы ответов объявлены `.strict()`. Новое поле верхнего уровня, новое значение перечисления или смена типа поля ломают разбор в уже открытой вкладке и в старой мобильной сборке. Новые поля добавляй во вложенные объекты без `.strict()`: лишние ключи там отбрасываются. Остальные изменения выпускай вместе с клиентом и учитывай открытые вкладки. Пример — смена `goalSchema.deadline` с `datetime` на дату (задача 02).
- Все тексты — по-русски и на «ты» (задача 01). Говорящие места — тоном человека (задача 03).
- «Сегодня» вычисляется только по правилу задачи 02. Своих вычислений даты в экранах не делать.
- «При входе» в задачах 09, 20 и 21 — открытие приложения в видимой вкладке (определение посещения — задача 21). Это не ввод пароля: сессия продлевается сама до 90 дней (`SESSION_ABSOLUTE_TTL_DAYS` в `backend/src/env.ts`), и человек может не вводить пароль неделями.
- Удаление задач, целей, этапов, шагов, заметок и привычек — только через корзину (задача 11, решение владельца). Каждый новый читатель данных скрывает удалённое.
- Каждая новая сущность попадает в выгрузку (задача 40) и удаляется вместе с аккаунтом (задача 41).
- Каждое пустое место показывает объяснение и кнопку создания (задача 36).
- Оформление — по [docs/DESIGN.md](../docs/DESIGN.md): токены темы, варианты `Typography`, общие блоки `webapp/src/components/dashboard`. Задачи 45–49 переводят экраны в стиль «Ночной старт».
- После задачи — обновить реестр возможностей в [CHECKLIST.md](../CHECKLIST.md).
- E2E — только для главного пути (задача 43). Браузер и E2E запускаются по запросу владельца.
