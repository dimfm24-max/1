# 36. Пустые экраны: объяснение и кнопка создания

| Поле | Значение |
| --- | --- |
| ТЗ | §7 «Первый вход» (на пустых экранах — короткое объяснение и кнопка создания) |
| Этап сборки | Сквозная возможность |
| Зависит от | задачи экранов, которые проверяются |
| Состояние | частично |

## Что есть сейчас

- На части экранов есть пояснение, но нет кнопки создания. Пример — пустой план дня: «На этот день ничего не запланировано…» без кнопки (`webapp/src/features/day/pages.tsx`).
- Компонент пустого состояния есть в наборе: `webapp/src/components/ui/empty.tsx`.

## Что сделать

Каждый пустой экран и список показывает короткое объяснение и кнопку создания. Кнопка сразу открывает создание: форму или поле с фокусом.

Список мест:

- «Сегодня»: нет задач, нет главной цели;
- «Цели»: нет дела жизни, нет целей, этап без шагов, пустой архив;
- «Привычки»;
- «Заметки»;
- «Статистика»: нет данных за период;
- «Календарь»: пустой день;
- корзина;
- цитаты, категории, шаблоны дня, свои поля;
- центр уведомлений;
- поиск: ничего не найдено;
- доступ по ссылке: ссылка выключена;
- результат задачи: вложений нет.

## Критерии приёмки

- [ ] Каждое место из списка показывает объяснение и кнопку.
- [ ] Кнопка ведёт к созданию без лишних переходов.
- [ ] Все пустые экраны, списки и плитки используют один компонент `Empty`. Внутри плитки — размер `sm`.

## Подводные камни

- Делай вместе с каждым экраном, а в конце проверь весь список. Иначе новые экраны появятся без пустого состояния.
- Там, где создавать нечего (статистика, поиск, центр уведомлений), кнопка ведёт к действию, которое даст данные: «Запланировать день», «Очистить поиск».
- Тексты — на «ты» (задача 01). Тон для пустого плана дня — из каталога (задача 03).
- Работа над стилем рисует пустые плитки «Сегодня» без `Empty`. Каждая функция пишет свой текст и кнопку внутри `DashboardTile`: `TodayWidgets.tsx`, `TodayGoalTiles.tsx`, `HabitStreaksTile.tsx`. Это расходится с критерием, а `docs/DESIGN.md` отсылает пустые состояния к этой задаче. У `Empty` есть размер `sm` для вложения в карточку (`webapp/src/components/ui/empty.tsx`): переведи на него пустые плитки. Сейчас `Empty` используют только страницы ошибок `webapp/src/components/WebRouteSections.tsx`.
