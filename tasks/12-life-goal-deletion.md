# 12. Удаление «Дела вашей жизни»

| Поле | Значение |
| --- | --- |
| ТЗ | §13 (при удалении дела жизни спросить: удалить вместе с целями или открепить цели), §2 (дело жизни одно, перенос целей между делами жизни не предусмотрен) |
| Этап сборки | 2. Цели |
| Зависит от | 11 |
| Состояние | сделано |

## Что есть сейчас

- Дело жизни создаётся и переименовывается: `upsertLifeGoal`. Удалить его нельзя: маршрута нет.
- `Goal.lifeGoalId` обязателен. Каскад в БД удалит цели вместе с делом жизни.
- Отметка главной цели хранится в деле жизни: `LifeGoal.primaryGoalId` в `backend/prisma/schema/goals.prisma`.

## Что сделать

1. Кнопка «Удалить дело жизни» с вопросом:
   - «Удалить вместе с целями» — цели уходят в корзину (задача 11);
   - «Открепить цели» — цели остаются и продолжают работать.
2. После удаления новую цель завести нельзя, пока нет дела жизни (§2). Экран «Цели» предлагает создать новое дело жизни.
3. Открепленные цели показываются группой «Без дела жизни».

## Критерии приёмки

- [ ] Оба варианта работают и проверены интеграционными тестами.
- [ ] После «удалить вместе с целями» цели лежат в корзине и восстанавливаются.
- [ ] После «открепить» цели, их шаги и задачи дня работают как раньше.
- [ ] Главная цель не теряется при откреплении.
- [ ] Без дела жизни сервер отклоняет создание новой цели, хотя `Goal.lifeGoalId` стал необязательным (§2). Интеграционный тест.

## Подводные камни

- Для «открепить» `Goal.lifeGoalId` должен стать необязательным. Это миграция через Prisma. Проверь всех читателей, которые ждут дело жизни у цели: дерево, доступ по ссылке (`lifeGoalTitle`), статистику, мастер.
- Связь `Goal.lifeGoal` объявлена с `onDelete: Cascade` (`backend/prisma/schema/goals.prisma`). Удаление строки `LifeGoal` сразу и навсегда удалит все её цели, в том числе цели в корзине, вместе с этапами и шагами. Тогда «удалить вместе с целями» нельзя будет отменить из корзины. Смени связь на `onDelete: SetNull` в той же миграции. Интеграционный тест: после удаления дела жизни цель восстанавливается из корзины.
- Если отметку главной цели переносят из `LifeGoal.primaryGoalId` в другое место, существующие отметки нужно перенести. Перенос — в модуле `goals`, например при первом чтении, а не рукописным SQL (AGENTS.md).
- Отметка главной цели живёт в `LifeGoal`. Без дела жизни главная цель пропадёт, а «Сегодня» её показывает. Рекомендация: перенести отметку на уровень человека, например в настройки. Уникальный частичный индекс на `Goal` потребовал бы рукописного SQL — это только по явному запросу.
- Восстановление цели из корзины после удаления дела жизни — правило в задаче 11.
- Мастер (задача 07) не должен открываться снова после удаления дела жизни.

## Решения владельца

Решено владельцем 23.09.2026.

- Что происходит с откреплёнными целями, когда человек создаёт новое дело жизни? **Решение:** они сами прикрепляются к новому делу жизни.
