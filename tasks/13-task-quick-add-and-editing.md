# 13. Задача дня: быстрое добавление и карточка задачи

| Поле | Значение |
| --- | --- |
| ТЗ | §3 «День» (время начала, длительность, приоритет, подзадачи, быстрое добавление), §12 (длительность по умолчанию) |
| Этап сборки | 3. День |
| Зависит от | 01, 02, 11 |
| Состояние | частично |

## Что есть сейчас

- Форма «Новая задача» в `webapp/src/features/day/pages.tsx`: название, время, приоритет, категория, кнопка «Добавить».
- Enter в поле названия не добавляет задачу: поля не внутри `<form>`, кнопка работает только по щелчку.
- Длительность в форме не задаётся. Сервер берёт её из настроек.
- Строка задачи `webapp/src/features/day/TaskRow.tsx`: галочка, подзадачи (добавить, отметить), «На завтра», «Отпустить», «Удалить».
- API меняет все поля задачи (`PATCH /api/day/tasks/{taskId}`), но экран не даёт изменить название, описание, время, длительность, приоритет, категорию, цвет и шаг.
- Подзадачу нельзя переименовать или удалить на экране. API для этого есть.
- В домене дня есть `suggestStartMinute` — подбор ближайшего свободного времени (`backend/src/modules/day/domain/schedule.ts`).

## Что сделать

1. Быстрое добавление: одно поле названия, Enter — задача появилась. Остальные свойства — потом, в карточке.
2. Карточка задачи — боковая панель по щелчку на задаче:
   - название (до 200 знаков), описание (без предела);
   - время начала и длительность (по умолчанию — из настроек);
   - приоритет: обычная, важная, срочная;
   - категория и свой цвет (задача 14);
   - шаг цели (задача 16);
   - подзадачи: добавить, переименовать, отметить, удалить;
   - напоминание (задача 31), повтор (задача 18), результат (задача 19), заметки (задача 27), свои поля (задача 33).
3. Задачи без времени — отдельный список «в течение дня».
4. Удаление — в корзину (задача 11), с кнопкой «Отменить».
5. Все поля времени и даты — в формате ТЗ (задача 01).

## Критерии приёмки

- [ ] Набрал название, нажал Enter — задача в плане, поле очищено, фокус остался в поле.
- [ ] Любое свойство задачи меняется в карточке и сохраняется.
- [ ] Подзадачу можно добавить, переименовать, отметить и удалить.
- [ ] Новая задача получает длительность из настроек.
- [ ] Приоритет виден в плане: важная и срочная отличаются от обычной.

## Подводные камни

- Контракт `updateTaskRequestSchema` не меняет дату задачи: перенос идёт через `resolve`. Перетаскивание на другой день (задача 28) потребует даты в правке или отдельного действия. Реши заранее.
- После правки сбрасывай кэш обоих дней, если задача сменила дату (`dayQueryKeys`).
- Выполненная задача: снять галочку можно. Сгоревшая задача — только просмотр. Рекомендация: сгоревшую можно вернуть в план отдельным действием переноса.
- Нужно ли отмечать задачу выполненной, когда отмечены все подзадачи? Рекомендация: нет, человек отмечает сам.
- Быстрое добавление без времени не участвует в поиске пересечений. Это нормально: пересечения считаются только у задач со временем.
