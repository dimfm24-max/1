## Что есть сейчас

- Своих полей нет.

## Что сделать

1. «Настройки → Свои поля»: отдельные списки для задач и для целей.
2. Поле: название, тип — текст, число, дата, список вариантов, флажок. У списка — варианты. Человек выбирает несколько вариантов сразу (решение владельца).
3. Поле можно переименовать, изменить варианты, удалить.
4. В карточке задачи и цели — значения своих полей.
5. Сервер проверяет значение по типу поля.
6. Хранение: определения полей (человек, вид сущности, тип, название, варианты, порядок) и значения (поле, сущность, значение).

## Критерии приёмки

- [ ] Поле каждого из пяти типов создаётся и заполняется у задачи и у цели.
- [ ] Неверное значение (текст в числовом поле) отклоняется сервером.
- [ ] Удаление поля предупреждает, сколько значений удалится.
- [ ] Дата в поле — в формате ТЗ.

## Подводные камни

- Смена типа поля с заполненными значениями. Рекомендация: тип менять нельзя, только создать новое поле.
- Удаление варианта списка, который уже выбран. Рекомендация: вариант убирается из значений с предупреждением.
- Шаблоны дня (задача 17) и повторы (задача 18): копировать ли значения? Рекомендация: нет в первой версии.
- Дата — без времени (задача 02). Число — десятичное, как показатель цели.
- Значения сущностей в корзине (задача 11) живут до окончательного удаления.
- Выгрузка (задача 40) включает поля и значения.
- Длина названия поля — до 200 знаков.
- Значение списка — массив выбранных вариантов. Храни id вариантов, а не текст: переименование варианта не ломает значения. Удаление варианта убирает его из всех значений.
