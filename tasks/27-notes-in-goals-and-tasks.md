# 27. Заметки внутри целей и задач

| Поле | Значение |
| --- | --- |
| ТЗ | §6 (Заметки: свободные записи, с привязкой к цели или без; заметки живут и отдельным разделом, и внутри целей и задач) |
| Этап сборки | 7. Заметки |
| Зависит от | 08, 11, 13 |
| Состояние | частично |

## Что есть сейчас

- Раздел `/app/notes` и модуль `backend/src/modules/notes`: свободные записи, необязательная привязка к цели, правка, удаление.
- Удаление заметки — сразу, без подтверждения.
- Внутри карточки цели заметок не видно.
- Привязки к задаче нет: у `Note` есть только `goalId`.
- Заметка переживает удаление цели: связь очищается, текст остаётся.

## Что сделать

1. Привязка заметки к задаче.
2. В карточке цели — заметки цели и кнопка «Добавить заметку».
3. В карточке задачи (задача 13) — то же.
4. Раздел «Заметки»: все заметки и фильтр — все, без привязки, по цели, по задаче.
5. Привязку можно сменить или снять.
6. Удаление — через корзину (задача 11).

## Критерии приёмки

- [ ] Заметка создаётся из карточки цели и видна там и в разделе «Заметки».
- [ ] Заметка создаётся из карточки задачи и видна там и в разделе.
- [ ] Окончательное удаление задачи оставляет заметку без привязки.
- [ ] Фильтр раздела работает.

## Подводные камни

- Заметка может ссылаться на цель или на задачу. Рекомендация: одна привязка, не обе. Задача и так связана с целью через шаг.
- Задача в корзине (задача 11): заметка остаётся, связь сохраняется до окончательного удаления.
- Много заметок: раздел отдаёт все сразу. Нужна постраничная выдача (задача 37).
- Поиск (задача 32) ищет по заметкам. Выгрузка (задача 40) их включает.
