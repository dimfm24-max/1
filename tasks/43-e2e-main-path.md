## Что есть сейчас

- Playwright-сценарии есть только для входа и аватара: `webapp/e2e/specs/auth.spec.ts`, `avatar.spec.ts`.

## Что сделать

Один сценарий главного пути:

1. Регистрация.
2. Мастер: тон, горизонт, дело жизни, цель с этапом и шагом.
3. Шаг ставится в план на завтра.
4. Переход на завтрашний день.
5. Задача выполнена, шаг отмечен выполненным.
6. «Сегодня» показывает продвижение главной цели.

## Критерии приёмки

- [ ] Сценарий проходит на чистой тестовой базе.
- [ ] Проверки — по исходам (сохранённые данные, переходы) и test ID, не по текстам (AGENTS.md).

## Подводные камни

- «Завтра» зависит от часов. Фиксируй время браузера в тесте или вычисляй дату от него.
- Пояс тестового браузера и начало дня (задача 02) влияют на «сегодня».
- Подтверждение почты (задача 05): в тестовом окружении ссылка берётся из консольной доставки или из БД.
- Продвижение цели от выполненного шага видно только при способе «автоматически из шагов». Сценарий выбирает этот способ в мастере или берёт значение по умолчанию из решения задачи 07. Иначе шаг 6 не пройдёт.
- Запуск браузера и E2E — только по запросу владельца (AGENTS.md). Сценарий пишется в задаче, запускается по запросу.

## Проверки

- `bun run --cwd webapp e2e -- main-path.spec.ts` — по запросу владельца
